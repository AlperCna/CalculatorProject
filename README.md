# Calculator

A basic **calculator** application for arithmetic operations — addition, subtraction, multiplication, and division — built with **Java**.

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white)

## ✨ Features
- Basic arithmetic operations
- Simple, easy-to-use interface

## 🛠️ Built With
- Java (NetBeans, Ant build)

## 🚀 Run
Open the project in NetBeans and run, or build with Ant:
```bash
ant run
```
